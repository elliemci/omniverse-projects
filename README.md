# Omniverse Projects

My Omniverse Kit work: a few custom Kit apps and extensions built from NVIDIA's Kit App Template, plus a set of OpenUSD factory scenes that I used to try them out. There are two projects in one tree: (1) creating Kit applications from templates and adding extensions to them, and (2) writing an Omniverse extension in Python (a UI extension with a menu entry that grows into one that spawns USD assets).

> **Requirements:** Windows 10/11 or Linux (Ubuntu 22.04+), an NVIDIA RTX GPU, a recent NVIDIA driver, Git, and internet access (the Kit SDK and extensions are downloaded on build). The Kit SDK itself is **not** in this repo. The README that came with the template lists the exact driver versions and the C++ build tools needed on Windows (see "What came from the template").

### How to run

The apps are built with the template's `repo` tool:

```
./repo.sh build      # Windows: .\repo.bat build
./repo.sh launch     # then pick one of the four apps
```

The first launch can take 5 to 8 minutes while shaders compile.

Project 1 An Introduction to Developing With NVIDIA Omniverse is the four `.kit` files above. Project 2 Creating an Omniverse Extension With Python lives in `omniverse-kit-app-extensions/source/extensions/ellies.python_ui_extension/ellies/python_ui_extension/` (the nested folders are template output and I will tidy them later).
Project 3 Extend Omniverse Kit Applications for Building Digital Twins experimenting adding physics to assets, `Factory_Lite_ConveyorBelt_Physics.usd`, mesuring, applying markups, waypoints `Factory_Lite_Waypoints.usd` and `Factory_Lite_mesur.usd`, and creating sections `Proposal_A`

## What came from the tutorial and the template

This repo started as a clone of NVIDIA's Omniverse Kit App Template (`kit-app-template`, history up to KAT 109.0.3 by NVIDIA authors). The template gives you a `repo` tool that generates, builds, launches and packages Kit apps and extensions from templates. The NVIDIA README I replaced pointed to these, which are the originals:

- [Kit SDK Companion Tutorial](https://docs.omniverse.nvidia.com/kit/docs/kit-app-template/latest/docs/intro.html)
- [Developing an Omniverse Kit-Based Application (NVIDIA DLI course, login required)](https://learn.nvidia.com/courses/course-detail?course_id=course-v1:DLI+S-OV-11+V1)
-[Creating an Omniverse Extension With Python, (NVIDIA DLI course, login required)](https://learn.nvidia.com/courses/course?course_id=course-v1:DLI+S-OV-16+V1&unit=block-v1:DLI+S-OV-16+V1+type@vertical+block@dd9301d8b2694519b204c3434a0f4296)
- [Extend Omniverse Kit Applications for Building Digital Twins (NVIDIA DLI course, login required)](https://learn.nvidia.com/courses/course?course_id=course-v1:DLI+S-OV-13+V1&unit=block-v1:DLI+S-OV-13+V1+type@vertical+block@d1fe256beea34694a7e9740f765cc671)

Not written by me, and left as it was:

- `templates/`, `tools/`, `.vscode/`, `.github/`, `readme-assets/` (including its `additional-docs`), `repo.sh`, `repo.bat`, `repo_tools.toml`, `CHANGELOG.md`.
- `LICENSE`, `SECURITY.md` and `PRODUCT_TERMS_OMNIVERSE`, which are NVIDIA's.
- The boilerplate inside my extensions: the file headers say NVIDIA copyright, since the code was generated from the templates. My additions are the spawn code described above.

## Shared folders and dependency chains

- `omniverse-kit-app-extensions/source/apps/` -> each `.kit` file lists its extensions. `ellies.usd_explorer.kit` enables `ellie.first_usd_explorer_setup_extension` and `ellies.python_ui_extension`. `ellies.usd_composer.kit` enables `ellies.usd_composer_setup_extension`.
- `rendered_template_metadata.json` records what the template tool generated (auto-generated, do not edit).
- Scene chain: `Factory_Layout.usda` is the layout entry point, and the `Factory_Lite` assembly pulls its parts from `Factory_Lite/SubUSDs/` (with textures and an MDL material beside them). **TODO (Ellie): confirm which assembly references which.**
- The spawn extension loads cardboard boxes and pallets over HTTP from NVIDIA's content server, so it needs internet and those files to stay online.
